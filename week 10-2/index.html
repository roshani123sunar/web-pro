Part 02 · Git Practice

Git and Version Control

The following exercises demonstrate repository initialization, commits, branching, merging, and remote repositories.

EXERCISE 01

Create Your First Git Repository

Goal: Initialize a Git repository, create a file, and make the first commit.

I started by checking Git and creating a repository. I created an index.html file, checked its status, staged the file, and made my first commit. 

git --version

git init -b main

git status

git add index.html

git commit -m "Initial commit: add index.html"

git log --oneline

My actual first commit:

aa26e4e Initial commit: add index.html
Result: Git successfully tracked my index.html file after staging and committing it.
First commit completed
EXERCISE 02

Create a Branch and Merge It

Goal: Create a feature branch, make changes, and merge them into the main branch.

I created a new branch called feature-style. On this branch, I added a basic stylesheet and committed the changes. I then switched to the main branch and checked the commit history. 

git checkout -b feature-style

git add style.css

git commit -m "Add basic stylesheet"

git checkout main

git merge feature-style

git log --oneline --graph --all

My recorded commits:

  • 4103979 - Add basic stylesheet
  • 393aa9f - Add styles to stylesheet
  • aa26e4e - Initial commit: add index.html
Result: I learned how branches separate changes and how Git displays commit history using a graph.
Branch practice completed

EXTRA PRACTICE

Creating a Pull Request

Goal: Understand the GitHub collaboration workflow by creating a branch, pushing it, opening a pull request, and merging it.

I created a separate branch called add-readme and added a README file. After pushing the branch, I practiced the pull request and merge process. 

git checkout -b add-readme

git add README.md

git commit -m "Add project README"

git push -u origin add-readme

git log --oneline --graph --all

My recorded commits:

  • 168f5b0 - Add project README
  • 346d744 - Merge pull request #1
Result: I understood how a pull request allows changes from one branch to be reviewed and merged into another branch.
Pull request merged

Understand a 404 Error Page

Goal: Understand what happens when a visitor opens a URL that does not exist.

A 404 error occurs when the requested page cannot be found. I tested a missing HTML file through my GitHub Pages URL.

My observation:

  • The browser displays a 404 error.
  • A custom error page can help visitors return to the homepage.
Result: I learned why websites need a helpful error page when visitors open an unavailable URL.
