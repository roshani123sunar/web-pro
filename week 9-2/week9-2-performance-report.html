4. Optimizations Applied

1. External CSS

I moved the CSS styles into a separate file called style.css instead of keeping them inside the HTML document. This makes the code easier to organize and maintain.

<link rel="stylesheet" href="style.css">

2. External JavaScript

I moved the JavaScript code into a separate file called script.js to keep the HTML document more organized.

<script src="script.js" defer></script>

3. Deferred JavaScript Loading

I added the defer attribute to the script tag. This allows the browser to download the JavaScript while parsing the HTML and execute it after HTML parsing is complete.

<script src="script.js" defer></script>

5. What Changed After Optimization?

  • CSS and JavaScript are now stored in separate files, making the project easier to organize.
  • The defer attribute allows JavaScript to download without interrupting HTML parsing.
  • First Contentful Paint improved from 1,171 ms to 1,076 ms.
  • Largest Contentful Paint improved from 1,171 ms to 1,159 ms.
  • Total Blocking Time decreased from 48 ms to 31 ms.
  • Speed Index changed from 1,276 ms to 1,441 ms, meaning this metric became slightly slower.

Both versions received a Lighthouse Performance score of 100/100. Some loading metrics improved, while Speed Index became slower and the overall performance score remained the same.

6. Conclusion

Through this task, I learned how separating CSS and JavaScript and using deferred loading can make website code easier to manage. Comparing the Lighthouse results also helped me understand how optimization can affect different performance metrics.
