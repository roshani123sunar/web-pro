01. Step Loop

A for loop repeats a block of code several times. It has three main parts:

  • Initialization: Starts the counter.
  • Condition: Checks whether the loop continues.
  • Update: Changes the counter after each repetition.

Example JavaScript Code

for (let i = 1; i <= 5; i++) {
    console.log('Step ' + i);
}

This loop starts at 1 and repeats until it reaches 5.

02. Fruit Array Loop

A for...of loop goes through each item in an array. It displays each fruit one by one.

Example JavaScript Code

let fruits = ['apple', 'banana', 'cherry'];

for (let fruit of fruits) {
    console.log(fruit);
}
