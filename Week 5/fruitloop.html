01. Step Loop

A for loop repeats a block of code several times. It uses three main parts:

  • Initialization: Starts the counter.
  • Condition: Checks whether the loop should continue.
  • Update: Changes the counter after each repetition.

Example JavaScript Code

for (let i = 1; i <= 5; i++) {
    console.log('Step ' + i);
}

This loop starts at 1 and repeats until it reaches 5. Each time, it prints the current step.
