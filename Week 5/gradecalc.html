JavaScript Conditional Statements

Programming Homework

Conditional statements allow JavaScript to make decisions. The if, else if, and else statements check conditions and execute different code depending on the result.

Example JavaScript Code:

let score = 85;

if (score >= 90) {
    console.log('A');
}
else if (score >= 80) {
    console.log('B');
}
else if (score >= 70) {
    console.log('C');
}
else {
    console.log('F');
}

JavaScript checks each condition in order. When it finds the first true condition, it executes that result and skips the remaining conditions.
