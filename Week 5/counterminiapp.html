About This Project

This mini-app demonstrates JavaScript variables, functions, and DOM manipulation.

A variable stores the counter value. Functions change the value, and DOM manipulation updates the number displayed on the webpage.

JavaScript Example Code

let count = 0;

function change(amount) {
    count = count + amount;
    document.getElementById('count').textContent = count;
}

function reset() {
    count = 0;
    document.getElementById('count').textContent = 0;
}
